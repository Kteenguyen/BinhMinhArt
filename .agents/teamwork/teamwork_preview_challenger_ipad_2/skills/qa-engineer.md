# QA Engineer Methodology Summary
Source: /Users/mac/.gemini/config/skills/qa-engineer/SKILL.md

Core Methodology:
- Shift-Left Testing & Testing Pyramid: verify data persistence, API contracts, and UI layer.
- Boundary Value Analysis (BVA) & Equivalence Partitioning: test extreme strings, long inputs, zero/null/overflow numbers.
- Automated verification: execute automated tests, inspect real DOM bounding boxes and computed styles.
- Defect logging: precise reproduction steps, evidence, and clear root-cause assessment.
